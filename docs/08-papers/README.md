# 08 · 论文笔记

本目录用于记录重要 LLM 论文与技术报告。

## 推荐记录格式

每篇论文尽量保持：

1. 论文解决什么问题？
2. 核心创新是什么？
3. 方法结构图 / 公式是什么？
4. 相比基线提升在哪里？
5. 代价是什么？
6. 对后续模型有什么影响？
7. 自己仍然没想明白的问题。
