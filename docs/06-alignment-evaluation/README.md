# 06 · 对齐与评测

本目录记录大语言模型后训练与能力评估相关知识。

## 重点主题

- Supervised Fine-Tuning（SFT）
- Preference Optimization
- Reward Modeling
- 模型评测方法
- Benchmark 设计
- LLM-as-a-Judge

## 学习目标

1. 理解基础模型如何经过后训练变成可用助手；
2. 理解常见偏好优化方法之间的区别；
3. 理解 Benchmark 指标能说明什么、不能说明什么；
4. 学会区分模型能力、对齐程度与实际使用体验。
